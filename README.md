# Device Asset Intake

Scan device label QR codes and barcodes (HP, Dell, Lenovo, Fujitsu, Apple, Samsung, Microsoft and others) into a register, then export to Excel or CSV.

- **Live scan**: phone or webcam camera, continuous scanning
- **USB/Bluetooth scanners**: keyboard-wedge input into the scan box
- **Photo of label**: decode QR from photos

Everything runs in the browser. Scans are stored only in that browser's local storage; nothing is sent to a server.
